# Ansari Huzair — Portfolio

Personal portfolio built with Next.js 15, TypeScript, Tailwind CSS v4, and Framer Motion.

## Setup

```bash
# Prerequisites: Node 20+
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
